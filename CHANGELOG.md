## 📌 Notas sobre Versionamento

Versionamento segue [Semantic Versioning](https://semver.org/):
- **MAJOR.MINOR.PATCH**
- **MAJOR:** Mudanças incompatíveis
- **MINOR:** Novas funcionalidades compatíveis
- **PATCH:** Correções de bugs

## 🔄 Como Atualizar

### Verificar Versão Atual
Abra `IC_Financial.xlsx` → Menu → Sobre → Versão

### Atualizar para Novo Release
1. Vá em [Releases](../../releases)
2. Baixe a versão mais recente
3. Substitua seu arquivo
4. Faça backup do antigo
