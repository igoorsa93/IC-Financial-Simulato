# 💼 IC Financial Simulator

Simuladores interativos de investimentos em **Fundos de Investimento Imobiliário (FIIs)**.

---

## 📊 Ferramentas Disponíveis

### 1. **IC Financial Simulator** 
*Versão padrão com análise completa de investimentos*

**Arquivo:** `IC_Financial_Simulator.xlsx` (28 KB)

**Funcionalidades:**
- Cálculos de juros compostos com aportes mensais
- Projeções de patrimônio (2, 5, 10, 20, 30 anos)
- Análise de metas financeiras
- Alocação dinâmica por perfil de investidor (Conservador, Moderado, Agressivo)
- Referência de FIIs reais com yields e cotações
- Cenários de projeção automáticos

---

### 2. **IC Financial** 
*Versão expandida com análise aprofundada*

**Arquivo:** `IC_Finacial.xlsx` (136 KB)

**Funcionalidades:**
- Simulação avançada de investimentos
- Análise detalhada de carteiras
- Ferramentas complementares de planejamento financeiro
- Dados estendidos e comparativos

---

## 🚀 Como Usar

1. **Escolha uma versão:**
   - `IC_Financial_Simulator.xlsx` — Simulação padrão
   - `IC_Finacial.xlsx` — Análise aprofundada

2. **Abra no Excel** e preencha os campos destacados

3. **Veja as projeções** atualizarem automaticamente
