# 💼 IC Financial Simulator

Simulador interativo de investimentos em **Fundos de Investimento Imobiliário (FIIs)**.

## 📊 Repositórios

Este espaço consolida dois repositórios principais:

### 1. **IC Financial Simulator** — Planilha Excel
Ferramenta interativa para simulação e planejamento de investimentos em FIIs.

**Funcionalidades:**
- Cálculos de juros compostos com aportes mensais
- Projeções de patrimônio (2, 5, 10, 20, 30 anos)
- Análise de metas financeiras
- Alocação dinâmica por perfil de investidor
- Referência de FIIs reais com yields

**Arquivo:** `IC_Financial_Simulator.xlsx`

### 2. **Documentação Técnica** — Repositório Complementar
Documentação, guias e referências técnicas do projeto.

---

## 🚀 Como Usar

1. Abra `IC_Financial_Simulator.xlsx` no Excel
2. Preencha os campos em azul com seus dados
3. Veja as projeções atualizarem automaticamente
